1. innerHTML sink (from location.search param 'name')

Classic DOM XSS: element.innerHTML = source. Source: location.search via URLSearchParams.
Auto-runs on page load using ?name= parameter.

2. document.write sink

Unsafe sink: document.write(source). Source: query param ?msg=.
Directly writes user input into document stream.

3. eval sink

Unsafe sink: eval(source). Source: query param ?expr=.

4. setTimeout string sink

setTimeout(string, ms) acts like eval. Source: ?t=.

5. setInterval string sink

setInterval(string, ms) sink. Source: ?i=.

6. Function constructor sink

new Function(source)() sink. Source: ?fn=.

7. location.hash → innerHTML (hash-based XSS)

Source: location.hash into innerHTML. Try #<svg/onload=alert(7)>
Hash will render here automatically.

8. location.href open redirect

location.href = source - open redirect / javascript: URI sink. Source: ?next=.

9. location.assign / location.replace open redirect

location.replace(source). Source: ?r=.

10. script.src assignment (arbitrary script load)

script.src = source allows loading attacker-controlled JS. Source: ?s=.

11. script.textContent (inline script injection)

Setting script.textContent = source after appending won't execute in modern browsers, but assigning before append does. Source: ?scode=.

12. iframe.src javascript: URI sink

iframe.src = 'javascript:' + source executes code in parent context in some browsers/settings.

13. element.setAttribute on event handlers / href

Setting setAttribute('onclick'|'href', source) allows javascript: URIs or event handlers. Source: ?handler=.

14. outerHTML sink

element.outerHTML = source replaces element with attacker markup.
Original element (v14_target)

15. insertAdjacentHTML sink

element.insertAdjacentHTML('beforeend', source).

16. document.domain manipulation

Setting document.domain = source from a param can weaken origin boundaries between subdomains.

17. Cookie manipulation (cookie injection / session fixation)

document.cookie = source allows arbitrary cookie setting / HttpOnly bypass attempts.

18. localStorage stored XSS

Data stored in localStorage via ?note= is later rendered with innerHTML (stored DOM XSS).

19. sessionStorage XSS

Same pattern as above but using sessionStorage.

20. postMessage without origin check (message listener)

window.addEventListener('message', ...) with NO origin check — accept messages from any origin.
Any window can postMessage to this page and trigger eval. Open this lab in a frame from any origin and try: frame.postMessage('alert(20)','*')

21. postMessage data → innerHTML

postMessage with weak origin check (just checks indexOf) and writes data.html to innerHTML.

22. JSONP injection (callback param)

Reads ?callback= and appends a script tag with that callback name — classic JSONP pattern allowing arbitrary JS execution via crafted callback name.

23. jQuery-style .html() / globalEval sinks

Simulated jQuery-style sinks: $(el).html(source) and $.globalEval(source). (Uses native innerHTML/eval as stand-in so the page works without jQuery.)

24. jQuery $() selector injection (XSS via hash HTML)

Old jQuery behavior: $(source) where source is a string starting with < creates HTML elements, executing scripts.

25. Dynamic createElement('script') + src

Creates a script via document.createElement('script') and sets .src from URL param ?lib=.

26. Range.createContextualFragment sink

range.createContextualFragment(source) parses HTML and inserts it, executing script-vector payloads.

27. XMLHttpRequest + DOMParser innerHTML

Fetches a URL (from ?fetch=), parses with DOMParser, and writes body into innerHTML. Also demonstrates reflected XSS via data: URIs.

28. history.pushState / replaceState with state → DOM

Reads state object and writes state.message into DOM via innerHTML (popstate-triggered XSS).

29. window.name → DOM

Reads window.name (cross-origin controllable) and writes to innerHTML.
Test with: window.open('dom-vuln-lab.html','<svg onload=alert(29)>')

30. document.referrer → DOM

Writes document.referrer into innerHTML — controllable by the linking page (e.g., referrer with javascript: or payload in query string).

31. CSS/style sink (backgroundImage url, expression legacy)

Assigns user input to element.style.backgroundImage = 'url(' + source + ')' — possible CSS injection / javascript: url() in older IE.
Styled box

32. href assignment with javascript: URI

Sets anchor.href = source without validating protocol — allows javascript: URIs.

33. form.action manipulation

Sets form.action = source — exfiltrates form data to attacker domain.

34. Inline event handler concatenation (onclick, onload, onerror)

Builds el.onclick = new Function(...) / inline string concat leading to handler injection.

35. DOM clobbering gadget

Code reads window.globalConfig.url without defining it — clobberable via an element with id="globalConfig" and a child name="url", leading to XSS in the redirect that follows.

36. Prototype pollution gadget

Performs a recursive merge of user-controlled options (from ?pollute=) — classic Object.prototype pollution gadget that can lead to XSS later when polluted keys are read.

37. WebSocket URL injection

new WebSocket(source) allows attacker-controlled WS endpoint (credential/data exfiltration over WS).

38. FileReader + drag-and-drop XSS

Reads dropped text files and writes contents to innerHTML — self-XSS on dropped content.
Drop a .txt/.html file here

39. Web Worker source injection

new Worker(source) from a blob/URL controlled by attacker (uses Blob URL from input).

40. Shadow DOM innerHTML sink

Attaches shadow root and writes user input to shadowRoot.innerHTML — classic DOM XSS within shadow DOM (scanners often miss this).

41. iframe srcdoc injection

iframe.srcdoc = source writes attacker-controlled HTML into a same-origin iframe.

42. Template element + clone + innerHTML

Uses <template> + content.cloneNode + innerHTML assignment to render untrusted data.

43. Anchor click → javascript: via hash

Link whose href is set from location.hash; clicking triggers the payload. Navigate to #javascript:alert(43) and click the link below.
Click me after setting hash to javascript:alert(43)

44. Expression parser (mock AngularJS sandbox bypass)

A toy expression evaluator that uses new Function('return ' + expr) under the hood — simulating Angular-style expression injection. Source: ?expr2=.

45. SAFE — textContent (false positive check)

Uses textContent (safe sink) — scanner should NOT flag this.

End of lab. Tips: test with payloads using ?name=, ?msg=, #hash, postMessage from cross-origin window, localStorage, window.name, referrer, etc.
